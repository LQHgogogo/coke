# 神临组的文字RPG游戏

## 项目简介

一款基于控制台的纯Java文字冒险 RPG 游戏。玩家扮演勇者，在随机生成的楼层中探索、战斗、成长，挑战越来越强的 BOSS，最终揭开世界背后的秘密。采用 JSON 持久化存档，支持多用户、角色死亡重开等完整游戏循环。

---

## 游戏背景

远古时代，世界被「虚空裂隙」撕裂，魔物从裂隙中涌出，肆虐大地。神殿骑士团倾尽全力封印了裂隙，但代价惨重——骑士团覆灭，封印之力随时间流逝日渐衰弱。

百年之后，裂隙再次松动。一位年轻的勇者响应神殿的召唤，踏入这片被诅咒的大地。每深入一层，魔物的力量便更加强大，而尘封的真相也随之浮现……

## 功能玩法介绍

### 账号系统
- **注册/登录**：支持多用户，每个用户独立存档
- **数据持久化**：存档自动保存到 `userdata.json`，退出不丢失

### 角色系统
- **自由加点**：创建角色时分配 20 点属性（生命/攻击/防御）
- **等级成长**：获取经验升级，每级 +10HP、+3 攻击、+2 防御
- **装备系统**：武器（增加攻击）和防具（增加防御），可自由装备/卸下
- **技能系统**：通过技能书学习技能，部分技能战斗中消耗生命值释放
- **背包系统**：可携带多种物品，药水、装备、金币

### 楼层探索
- **10 个房间/层**：随机生成战斗房、奖励房、剧情房、BOSS 房、空房间
- **每 3 层生成商店**：可购买药水、装备、技能书
- **房间状态**：已探索房间标记为「已探索」，不可重复进入
- **BOSS 标记**：BOSS 房以 `【BOSS】` 标签高亮显示

### 战斗系统
- **回合制**：玩家与敌人轮流行动
- **技能释放**：
  - 普通攻击：无消耗
  - 强力一击：消耗 5% 最大生命，2 倍攻击
  - 旋风斩：无消耗，1.5 倍攻击
  - 雷霆一击：消耗 10% 最大生命，2.5 倍攻击
  - 生命汲取：消耗 10 生命，回复随机血量
  - 圣光普照：消耗 5 生命，回复 30% 最大生命
- **战斗中可使用药水**：百分比回复生命
- **战后回复**：击败怪物后回复 30% 最大生命
- **BOSS 双技能**：BOSS 拥有两个技能，随机释放

### 敌人系统
- **4 种普通怪物**：初级士兵、敏捷刺客、重装坦克、神秘法师
- **6 种 BOSS**：幽影蛛皇、霜铠冰将、雷械巨核、枯瘴树灵、虚空魔神、焚岩督军
- **怪物复制机制**：每次遇敌从模板拷贝新实例，状态独立不继承
- **动态缩放**：怪物属性随楼层增长，BOSS 与普通怪各有独立成长曲线

### 奖励系统
- **战斗掉落**：击败怪物随机掉落装备、药水、技能书
- **奖励房间**：宝箱随机开出经验、金币、物品
- **剧情房间**：触发剧情获得经验，推进故事线

### 死亡与重开
- 角色死亡后可选「重新开始」或「退出游戏」
- 重新开始时自动清除旧存档，回到角色创建

## 功能实现

| 模块 | 说明 |
|------|------|
| `Access.java` | 程序入口，启动游戏 |
| `login.java` | 用户注册/登录，管理多用户存档 |
| `TextGame.java` | 游戏主循环，角色创建、楼层切换、房间选择、死亡处理 |
| `Floor.java` | 楼层生成（随机房间布局）、房间触发逻辑、战斗系统、商店系统 |
| `Hero.java` | 角色属性、装备、技能、背包、药水使用、升级 |
| `Character.java` | 角色基类（HP、攻击、防御、存活状态） |
| `Enemy.java` | 敌人数据、拷贝构造函数 |
| `Item.java` | 物品数据模型（武器/防具/药水/金币/技能书） |
| `ItemFactory.java` | 物品工厂，统一管理物品模板和掉落表 |
| `StoryManager.java` | 剧情系统，管理剧情进度和分支触发 |
| `User.java` | 用户数据模型，关联英雄角色 |
| `FileManager.java` | JSON 存档读写 |

---

## 核心技术运用

- **Java OOP**：继承（`Character` → `Hero`/`Enemy`）、封装、多态，类层次清晰
- **Gson 序列化**：`Gson` 库实现 JSON 双向转换，`transient` 排除运行时计算字段
- **文件 I/O**：`FileReader`/`FileWriter` 实现存档持久化，相对路径适配
- **随机生成**：`Random` 驱动楼层布局、怪物种类、掉落物品、奖励内容
- **链表结构**：`Floor` 通过 `nextFloor` 指针构成单向链表，实现楼层递增
- **控制流**：标签化 `break`/`continue` 实现多层循环跳出（楼层切换、死亡重开）
- **设计模式**：工厂模式（`ItemFactory`）、拷贝构造（`Enemy` 怪物实例化）
